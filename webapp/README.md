# CNC Design Studio - Web UI

**All-in-one web interface for parametric CAD and CAM.**

Design → Preview → Toolpath → G-code, all in your browser.

## Features

✓ **3D Preview** - Interactive Three.js viewer with orbit controls
✓ **Live Parameter Editing** - Adjust design parameters and regenerate instantly
✓ **Direct CAM** - Generate G-code without Fusion 360
✓ **2D Contour Toolpaths** - Optimized for plywood/sheet goods
✓ **Automatic Tabs** - Holding tabs to keep parts secure during cutting
✓ **Multi-pass Cutting** - Configurable depth of cut
✓ **Export Options** - Download STEP files and G-code

## Quick Start

### Local Mode (Recommended for development)

```bash
./run-studio.sh local
```

Open http://localhost:5000

### Container Mode (Podman)

```bash
# First time: install Podman
brew install podman
podman machine init
podman machine start

# Run the studio
./run-studio.sh container
```

## Usage

1. **Select a Part** - Click a part name in the sidebar (e.g., "hamper")
2. **View Preview** - 3D model loads automatically
3. **Edit Parameters** - Adjust dimensions in the right panel
4. **Update Preview** - Click "Update Preview" to regenerate
5. **Configure CAM** - Set tool diameter, speeds, feeds
6. **Generate G-code** - Click "Generate G-code" to download .nc file
7. **Load in Carbide Motion** - Upload the .nc file to your Shapeoko

## Controls

**3D Viewer:**
- **Left-click + drag** - Rotate view
- **Scroll wheel** - Zoom in/out

**Parameters:**
- Change any dimension
- Click "Update Preview" to see changes

**CAM Settings:**
- Tool Diameter: Default 6.35mm (1/4")
- Material Thickness: Depth of material to cut through
- Spindle RPM: Default 18000 (plywood)
- Feed Rate: Default 1500 mm/min (plywood)

## Architecture

```
webapp/
├── app.py              # Flask backend (API endpoints)
├── templates/
│   └── index.html      # Single-page UI with Three.js
└── README.md
```

**Backend (Flask):**
- `/api/parts` - List available parts
- `/api/part/<name>` - Get part metadata and parameters
- `/api/part/<name>/preview` - Generate 3D mesh for visualization
- `/api/part/<name>/gcode` - Generate G-code toolpath
- `/api/part/<name>/export/step` - Export STEP file
- `/api/tools` - List available tools
- `/api/machine` - Get machine constraints

**Frontend (JavaScript + Three.js):**
- 3D mesh rendering
- Parameter editing UI
- API communication
- File downloads

## CAM Features

The toolpath generator (`lib/cam.py`) supports:

**2D Contour Milling:**
- Outside/inside/on-line cutting
- Multi-pass depth control
- Configurable feeds and speeds
- Grbl-compatible G-code output

**Tabs (Holding):**
- Automatically places holding tabs
- Configurable tab width and height
- Evenly distributed around perimeter
- Only on final depth pass

**Safety:**
- Safe height for rapid moves
- Retract height between features
- Proper spindle control (M3/M5)
- 2-second spindle spin-up delay

## Generated G-code Format

```gcode
%
(Generated by CNC Toolpath Generator)
G21 (Metric)
G90 (Absolute positioning)
G17 (XY plane)
M3 S18000 (Spindle on)
G4 P2 (Pause for spindle)
...toolpath moves...
M5 (Spindle off)
G0 X0 Y0 (Return to origin)
M2 (Program end)
%
```

## Deployment

### Development (Local)
Best for designing and testing new parts:
```bash
source .venv/bin/activate
python webapp/app.py
```

### Production (Container)
Best for shared/persistent deployment:
```bash
# Build
podman build -t cnc-studio -f Containerfile .

# Run
podman run -d \
    -p 5000:5000 \
    -v $(pwd)/parts:/app/parts:Z \
    -v $(pwd)/exports:/app/exports:Z \
    --name cnc-studio \
    --restart unless-stopped \
    cnc-studio
```

Or use docker-compose:
```bash
podman-compose up -d
```

## Adding New Parts

1. Create `parts/my_part.py` using `lib/template.py`
2. Implement `build_part()` function
3. Reload the web UI
4. Your part appears in the sidebar automatically!

## Limitations

Current CAM implementation is optimized for:
- ✓ 2D contour cutting (exteriors and pockets)
- ✓ Flat sheet materials (plywood, aluminum, acrylic)
- ✓ Through-cuts and pockets

Not yet supported:
- ✗ 3D surfacing / contoured faces
- ✗ Drilling cycles
- ✗ Adaptive clearing
- ✗ Multiple setups

For complex 3D work, export STEP and use Fusion 360 CAM as before.

## Troubleshooting

**"Part not found"**
Make sure your part file is in the `parts/` directory and has a `.py` extension.

**"No build function found"**
Your part must have either `build_part()` or `build_hamper()` function.

**"Failed to generate mesh"**
The part geometry may be invalid. Check build123d errors in terminal.

**3D preview not showing**
Check browser console for errors. Make sure Three.js loaded (requires internet).

**G-code looks wrong**
Adjust CAM settings (tool diameter, material thickness). Preview in CAMotics or similar.
